# Security

This repository holds plugin manifests and skills only. It holds no credentials, and the plugin carries none.

To report a vulnerability in the WaveWise MCP server, the OAuth flow or this plugin, use the contact options at <https://wavewiseintelligence.com/contact> and mark the message "security". Please do not open a public issue for a vulnerability.

Scope: `https://mcp.wavewiseintelligence.com` (MCP, OAuth metadata and endpoints) and the consent page on the WaveWise Merchant app. Test only against a workspace you own; never against another merchant's data.
